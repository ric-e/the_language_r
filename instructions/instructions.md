# Learning R - Information and Instructions

This repository aims to document the learning of the R Programming Language. It combines the goals, work, and projects written during the learning process of `R`. It possesses a combination of R script files and Markdown Files.

## Daily Goals & Tasks

Each day, there will be a set of 2-4 different goals, which can range from learning simple data types, functions, to experimenting with libraries in `R`. Each goal is accomplished through a series of 1-3 tasks, of vary difficulty, complexity, and length, depending on the goal. Ideally, goals should be accomplished with a variety of introductory and mastery-oriented tasks.

### Progression

This Repository aims to explore and master the `R` Programming Language from its basics. It assumes the knowledge of universal coding practices and semantical logic that is associated with quality programming. Conversely, the work does not expect explicit knowledge of `R`'s specific syntax or any associated libraries and language-specific features. It aims to be thorough and detailed, yet avoid verbosity or unnecessarily simplistic work.


## Tools
This repository is a work stored on GitHub. For consistency, the work has been completed in the `RStudio` GUI, and will be saved as `.R` files.

### Packages & Libraries
The top-level references of every file will always include `library(package)` for whatever required library is used.

Although it will not explicity include the `install.packages()` console prompt, it is expected that this is completed before sourcing in `RStudio` to avoid any import errors.

Each file will not import from other `.R` files, although it will freely import `R` libraries.

## Organization
The work in this repository is organized into be in folders sorted by date.
